집중모드 시안 3종

목표 시간을 정하고 집중 시작 → 3·2·1 → 화면을 꽉 채우는 타이머 → 목표를 넘기면 '초과 집중' → 완료.
각 폰 화면을 직접 눌러 보세요. 오른쪽에서 시간을 빠르게 돌릴 수 있어요.

시연 속도

A등대 — 로고 캐릭터

밤바다 위 등대. 집중할수록 링이 차오르고 등대 불빛이 점점 밝게 돈다. 목표를 넘기면 숫자가 노랗게 바뀐다.

B다이얼 — 밝은 시계

눈금 다이얼에 노랑→주황 호가 돈다. 시작·종료 예정 시각을 같이 보여 줘서 '언제 끝나는지'가 바로 보인다.

C채움 — 초대형 숫자

브랜드 노랑이 바닥부터 화면을 채워 올라온다. 장식 없이 숫자만 크게. 화면 어디든 탭하면 일시정지.

공통으로 바뀌는 점 · 목표 집중 시간을 고른다(기본값 = 계획에 정한 1회 시간, 5분 단위, 프리셋 15·25·50·90) · 시작하면 상단 바·하단 탭 없이 전체 화면 · 목표를 채워도 멈추지 않고 '초과 집중'으로 이어간다 · 끝내면 판정하지 않고 집중한 시간 · 목표보다 몇 분 빨리/늦게만 보여 준다(일이 일찍 끝나서 누르는 경우가 더 많다) · 중간에 누르는 버튼도 '끝내기' 대신 '다 했어요'
실제 구현 때 정할 것 · 화면 꺼짐 방지(Wake Lock) · 목표 도달 알림(진동·소리) · 앱을 나갔다 와도 시간이 이어지게 시작 시각 기준 계산(지금 방식) · 일시정지 시간 기록 여부
